Metadata of publication.
type: Type of publication. Options are []
id: Unique integer identifier of publication.
attributes: Metadata of publication, the list consists of the following attributes:
    workflow: 
    online_date: Date of publication.
    offline_date: Date of removal, will be null in most cases.
    title: Title of publication.
    alternative_title: Alternative title of publication, will be empty in most cases.
    template: Template used for publication. Options are [].
    show_ads: Binary to display ads or hide them.
    comments: Binary to allow visitors of website to add comments to the publication.
    not_suitable_content: Binary to mark an article as being non advertiser friendly. Not consistently used by NH Nieuws.
    push_message_sent: Binary to send push notification through app upon publication.
    slug: Text reference to publication to add to url, often consists of the title, separated by '-'.
    image_id: Image id of header image. For older publications this is a default image.
    region_id: Integer identifier of region of publication.
    region_text: Text version of region, retrieved based on the region_id.
    sent_to_rpo: Binary to send the publication to the national broadcasting organisation (NOS).
    deleted: Binary to mark whether the publication has been deleted.
    changed: Date of last changes made to publication.
    meta_description: Text that shows in search results when displaying publication in (external) search engine. Describes the article in one sentence and ends with 'Lees het hele verhaal...'.
    has_video: Binary to mark whether the publication has a video.
    external_article_id: If the publication is sent to the national broadcasting organisation, this is an integer. If there is no such id or the publication is not sent elsewhere, this is null.
    is_breaking: Binary to show importance in frontend. Often a temporary variable that is quickly set to false.
    visible_just_in: Binary to show importance in frontend. Often a temporary variable that is quickly set to false.
    hide_most_read: Binary to show in 'most read' section on webpage.
    simplified_article_id: Unique integer ID of simplified article. If no such version is available, set to 0.
    throughput_delay": 1,
    external_url: If the publication is sent to the NOS, this shows the url of the NOS publication. If it is not exported, this is an empty string.
    episode_id: If the publication is part of a series, this is an integer with the episode number. If it is not part of a series, this is 0.
    is_external_url: Binary to show if there is an external url available.
    available_languages: List of languages the article is available in. Will usually be a list containing Arabic ("ar"), German ("de"), English ("en"), Spanish ("es"), French ("fr"), Polish ("pl"), Turkish ("tr"), Ukrainian ("uk")
relationships: Shows connections to other larger pieces of metadata, such as author and images.


Contents of article
There are several possible types here. For now, onlt the textual ones are covered. Other types are for example "image-video", "stream", "video", "image-item", "region", and "block-carousel".

type: "block-text"
id: Unique integer ID for a text block.
attributes: 
    text: HTML of text block.
    deleted: Binary marker to show if the text has been deleted from the publication
    changed: Date of last changes made to the text.
